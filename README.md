# AI Reply with the Chat

An experimental **Mozilla Thunderbird extension** that adds AI-powered email reply features.  
The extension integrates directly into Thunderbird’s message display and composition windows, allowing users to generate intelligent draft replies through the [Mistral AI API](https://docs.mistral.ai).

---

## 🧩 Purpose

This extension enhances Thunderbird by providing quick, context-aware email responses.  
It is designed for users who want to use generative AI to write or improve replies without leaving Thunderbird.

Key functions:
- Read message content when opened  
- Provide an **AI-generated reply suggestion** using Mistral  
- Insert generated text directly into the compose window  
- Offer manual configuration and triggering through menus or toolbar actions
